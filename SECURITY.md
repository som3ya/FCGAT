# Security policy

This project is intended for **defensive security research**.

## Do not upload malware

- Do **not** commit malware binaries, unpacked samples, or proprietary reverse-engineering artifacts to GitHub.
- Keep all malware samples and derived artifacts in a private, access-controlled location.

## Safe usage guidelines

- Use an isolated VM / sandbox.
- Disable shared folders / clipboard when handling malware.
- Follow your organization’s policies and local laws.

## Reporting security issues

If you discover a vulnerability in the code (e.g., unsafe file handling), please open an issue without attaching malware samples.
